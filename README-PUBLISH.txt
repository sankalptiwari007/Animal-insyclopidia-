PUBLIC HOSTING
GitHub Pages:
1. Create a PUBLIC GitHub repository.
2. Extract this ZIP.
3. Upload ALL HTML files to the repository ROOT.
4. Repository Settings → Pages.
5. Source: Deploy from a branch.
6. Branch: main.
7. Folder: / (root).
8. Save.
9. Wait for the deployment and open the provided github.io URL.

IMPORTANT
Do not upload only the ZIP. Extract it first.
Do not put index.html inside another folder.
Keep all HTML files together because the navigation uses relative paths.

IMAGE NOTE
The pages use remote image URLs and graceful fallbacks. If you want the site to remain fully independent of third-party image hosting, download properly licensed images and place them in an images/ folder, then update the image paths.
